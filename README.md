# Hari Prapan — Personal Research Website

This is a standalone GitHub Pages website for `HariPrapan`.

## Deploy

1. Create a new repository named `HariPrapan.github.io`.
2. Upload `index.html` and `style.css` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

Your site will be available at:

`https://hariprapan.github.io/`

## Customize

- Replace or add project links in `index.html`.
- Add a publications section when papers/preprints are ready.
- Add your email if you want it publicly visible.
- The site intentionally does not display a phone number.
